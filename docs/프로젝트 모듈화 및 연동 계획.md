## 2단계: 핵심 추론 및 수집 로직 개선 (WebRTC DataChannel 처리)

| 작업 내용 | 목표 | 관련 파일/모듈 |
| :--- | :--- | :--- |
| **A. 추론 로직 모듈화** | `main.py`의 `run_inference` 함수를 별도의 모듈로 분리하고, `SequenceCollector`도 함께 이동시켜 `main.py`의 역할은 **엔드포인트 처리**에만 집중하도록 합니다. | `main.py`, `inference_pipeline.py` (신규), `processing/predictor.py` |
| **B. DataChannel 퀴즈 파이프라인 구현** | `main.py`의 `websocket_endpoint`에서 DataChannel의 `flush` 신호 수신 시 추론을 수행하는 로직이 퀴즈 파이프라인(`2. 수어 단어 퀴즈 파이프라인`)에 맞게 동작하도록 확정합니다. <br> 특히, **추론 완료 후 S3 자율 저장 명령**을 내부적으로 처리하는 **비동기 백그라운드 태스크** 호출 로직을 설계합니다 (저장 모듈은 4단계에서 구현). | `main.py`, `inference_pipeline.py` |
| **C. 시퀀스 수집 안전성 강화** | `SequenceCollector`가 **시간 조건** 및 **프레임 수** 조건 모두로 수집을 안전하게 중단하도록 로직을 재검토합니다 (`main.py`에 정의된 `is_full` 로직을 사용). | `main.py` (`SequenceCollector`) |

## 3단계: Spring-FastAPI 내부 REST API 엔드포인트 구현

통합 파이프라인에서 Spring 서버가 FastAPI에 저장 명령을 내리는 내부 API 엔드포인트를 구현합니다.

| 작업 내용 | 목표 | 관련 파일/모듈 |
| :--- | :--- | :--- |
| **A. 상태 초기화/연결 정보 엔드포인트** | Spring이 FastAPI의 상태를 확인하고 WebRTC 연결 정보를 가져갈 수 있는 엔드포인트를 그대로 유지합니다. | `/health`, `/model/status`, `/config` (FastAPI) |
| **B. 개인 학습 저장 엔드포인트 (Spring → FastAPI)** | 개인 학습 파이프라인(`3. 수어 개인 학습 파이프라인`)의 **6단계**에 해당하는 엔드포인트 (`/fast-api/save-learning` 예시)를 구현합니다. 이 엔드포인트는 Spring으로부터 세션 ID와 학습 단어 정보를 받아, 해당 세션 ID의 수집된 프레임 데이터를 **저장 모듈로 전달**하는 역할을 수행합니다. | `main.py` (신규 `/internal/save-learning` 엔드포인트) |
| **C. 퀴즈 자율 저장 내부 호출 엔드포인트** | 퀴즈 파이프라인의 **6단계**에 해당하는 자율 저장 명령을 내부적으로 실행하기 위한 엔드포인트 (`/fast-api/save-quiz` 예시) 로직을 **비동기 백그라운드 태스크** 형태로 구현합니다. 이 엔드포인트는 외부 접근이 불가능하며, `run_inference` 완료 후 FastAPI 내부에서 호출됩니다. | `main.py`, `inference_pipeline.py` |

## 4단계: DB/S3 연동 모듈 인터페이스 정의 및 더미 구현 (모듈화)

향후 S3 버킷과 DB 스키마가 결정되어도 즉시 교체 가능하도록, 데이터 저장 로직을 완전히 모듈화하여 분리합니다.

| 작업 내용 | 목표 | 관련 파일/모듈 |
| :--- | :--- | :--- |
| **A. 데이터 저장 인터페이스 (추상화)** | **S3 저장**과 **DB 기록**에 대한 추상화 클래스 또는 함수를 정의합니다. 실제 S3, DB 연동 코드는 이 인터페이스 내부에 작성됩니다. | `storage/storage_interface.py` (신규) |
| **B. 학습 데이터 저장 구현** | 랜드마크 시퀀스를 받아 S3에 NPY/CSV로 저장하고, DB에 기록하는 로직을 \*\*더미(Mock)\*\*로 구현합니다. (실제 S3/DB 연동 코드는 추후 Spring/인프라 확정 후 작성) | `storage/s3_db_saver.py` (신규, 더미) |
| **C. 퀴즈 데이터 저장 구현** | 추론 결과(레이블/점수) 및 랜드마크 시퀀스를 받아 저장하는 로직을 \*\*더미(Mock)\*\*로 구현합니다. | `storage/s3_db_saver.py` (신규, 더미) |
| **D. 3단계 엔드포인트에 연동** | 3단계에서 구현한 내부 API 및 퀴즈 추론 완료 로직이 4단계에서 정의된 저장 모듈을 호출하도록 연결합니다. | `main.py`, `inference_pipeline.py` |
